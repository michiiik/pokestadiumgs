### Source and ABI findings

- Fade start returns zero for a null context or modes other than zero/one.
  Mode one becomes two; mode zero becomes three. Clear progress at 0x13 and
  store the duration byte at 0x12. Keep the word-sized `mode` and named word
  `one` on the left of both equality tests: literal-only comparisons reverse
  two branch operands. Reload the global root after the byte stores; caching
  every destination changes the target's alias-sensitive load sequence.
- Existing `StageFade_StartFromOpaque` and `StageFade_StartFromTransparent`
  implicitly forwarded the incoming argument register through a no-argument
  C call. The assembly callee consumes it as duration. Repair both definitions
  to take `s32 duration` and explicitly pass it. These exact-once companion
  edits were accepted with fade start; both previous wrapper bodies retain
  their original instruction bytes. Do not restore the incorrect `(void)` ABI.
- Callback polling with zero frames is unbounded. Otherwise use unsigned
  `while (frames-- > 0)`, not `!= 0`: IDO emits the target's SLTIU/XORI pair
  only for the relational form. Tick once after every callback, including the
  callback that ends the loop. Do not combine callback and loop conditions.
- Callback fade uses a function-scope word temporary and `while (active)`.
  Latch the first nonzero callback return and start the transparent fade.
  Continue invoking the callback while fading; re-read mode after each call.
  The exit iteration also ticks. Scoping the temporary inside the loop changes
  saved-register allocation; a do/while or inverted primary branch also drifts.
- Drawing reads a signed index byte at 0x16 into the word image table at 0x18.
  Inline array indexing matches; naming the index changes its temporary,
  and byte-pointer shifted arithmetic reverses an ADDU operand pair. Emit the
  cycle command with `gDPSetCycleType(..., G_CYC_1CYCLE)`.
- Established names come from `tools/s1_transfer.json` in the tooling checkout.
  Keep address-keyed symtab entries and add old-to-new compatibility aliases.
  Other source changes are mechanical caller/prototype name propagation.
