## Evolution method scan

`func_80063A8C` -> `Pokemon_FindEvolutionMethod` scans three-byte evolution
records selected by species from the 12-byte `D_8009D27C` pointer table.
The first species points to `D_8009CEE0`, whose bytes `01 10 02 00` encode
method 1, level 16, target species 2 and a terminator. The second points
to `D_8009CEE8`, containing `01 20 03 00` (level 32, target species 3).
`func_80064248` consumes the returned method while walking predecessor
species and adjusts the permitted level for method 1.

The function rejects species/target outside 1 through 251 and levels
outside 1 through 100, and handles a null evolution-list pointer. It returns
method 1 only when the supplied level reaches the record threshold; other
matching methods return directly. Missing targets return zero.

All 240 original bytes pass direct link verification and the normal
full-ROM gate. Direct method-byte reads preserve the original expression
load and promoted comparison value; the byte return type reproduces the
original loop branch/delay slots. No fake locals or output patches are used.
