## 2026-10-18: explicit pointer returns in three existing wrappers

`func_80069F20(arg0, 0, 0)`. The callee allocates and initializes an 0x80-byte
context, publishes it through `D_8009DF70`, and returns its saved allocation
pointer in v0 at 0x8006A12C. The wrapper's original 36 bytes preserve v0, and

The C definition now returns `void *` explicitly instead of hiding that value
behind a void declaration. This establishes the return contract, not a new
interpretation of the wrapper's existing name.
