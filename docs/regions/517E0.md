## Switch dispatchers: source case order and relocation equivalence (2026-08-30)

Constant-map switches decompile as `s32 result = 0; switch (arg0) { case N: result = X; break; ... } return result;` — IDO turns all but the last case into direct `li v0/jr ra` tails and shares the v1 epilogue between the last case and default. Case bodies are emitted in SOURCE order, not value order: `func_80053230` has `case 0x13` before `case 0x12` (read the body order from the .s labels, not the jtbl). The probe then reports `immediate_drift` at the `lw t6, %lo(jtbl)(at)` pair (normalized sim 1.0, raw ~0.97): the asm stub carries a symbol relocation where the C object resolves the section offset numerically. Relocation-equivalent; ROM gate verifies. Evidence: 3 (`func_80050DE4/80053230/800532F0`).
