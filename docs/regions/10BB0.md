## Side-tool recipe: LCS-diffing expected .s vs probe .o (2026-08-29)

- Expected: strip `%hi(D_8008D660)`/`%lo(D_8008D660)` to `0` on the raw line first, then split on `*/` and take the tail (drop trailing `/* */` comments); the earlier regex failed because the classic mnemonic class `[a-z0-9 .$-]` excludes `%`, and objdump is tab-separated (`addr:<TAB>word<TAB>mnemonic<TAB>operands`) so lines split cleanly on `\t`.
- Normalize: tokenize registers (`\b[avt][0-9]+\b` -> `R`, `zero` -> `Z`, `ra` -> `RA`), immediates (`0xN`/`-N` -> `#`) BEFORE collapsing whitespace; collapsing first glues registers to mnemonics and breaks the match.
- GNU objdump prints `move` for `or r,r,zero` and `li` for `addiu r,zero,imm`; map those back before comparing with the IDO `.s` spellings, or you will see spurious mnemonic diffs on every instruction.
